# 画廊图片

把图片放进这里，画廊就会自动显示。**唯一要注意的是：放完图要跑一次扫描。**

## 怎么用

1. 把图片丢进下面三个主文件夹之一（jpg / jpeg / png / webp / gif / avif）
2. 双击项目根目录的 `rescan.bat`（或者运行 `node tools/scan-gallery.mjs`）
3. 刷新网页

`edit.bat` 启动编辑器的时也会自动先扫一遍。

## 目录含义

| 文件夹 | 显示在哪 |
| --- | --- |
| `together/` | 首页「双人 / TOGETHER」图集 |
| `a-su/` | 阿苏角色页的「画廊」 |
| `pugua/` | 蒲瓜角色页的「画廊」 |

## 直接放图片 = 一张一张显示

```
a-su/
  01_a-su-standing.png
  02_a-su-head.png
```
排序按文件名（数字大小），所以想调整顺序就在前面加 `01_` `02_` 这样的前缀。

## 放子文件夹 = 一个「系列」

```
pugua/
  立绘三连/
    01.png
    02.png
    03.png
```

- 画廊里**只显示第一张**当封面，右上角标「×03」
- 点封面进入灯箱后，可以左右翻看这一组全部图片
- 组名默认用文件夹名

只支持**一层**子文件夹，再深就不会被扫描到。

## 标题和分类（可选）

主文件夹里可以放一个 `_meta.json`：

```json
{
  "01_a-su-standing.png": { "title": "立绘", "note": "早期版本", "cat": "立绘" },
  "02_a-su-head.png":     { "title": "头像", "note": "", "cat": "头像" }
}
```

- `title`：显示在卡片和灯箱里的标题，不写就用文件名（去掉 `01_` 前缀）
- `note`：小字说明
- `cat`：画廊顶部筛选按钮的分类，不写就是「单图」

系列文件夹里也可以放 `_meta.json`，除了单图字段外，还能用 `_title` / `_note` / `_cat` 描述整组。

## 生成的文件

扫描会写 `assets/js/gallery-index.js`。**这个文件不要手改**，每次扫描都会覆盖它。
